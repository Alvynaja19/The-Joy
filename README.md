# The Joy (HEY JOEY!) - Official Website & Catalog

Website katalog interaktif dan e-commerce hybrid untuk brand busana wanita **HEY JOEY!**. Dilengkapi dengan rak gantung pakaian interaktif (Wardrobe Rack), katalog koleksi harian, lookbook padu padan setelan, babak koleksi (chapters), serta alur pemesanan hybrid ke WhatsApp dan Shopee.

---

## Fitur Utama

- **Wardrobe Rack Interaktif:** Gantungan baju dinamis di bagian hero dengan transisi tampak depan dan tampak samping saat dipilih.
- **Katalog Koleksi Harian:** Menampilkan seluruh produk lengkap dengan filter 12 kategori, pencarian real-time, badge koleksi baru, dan format harga Rupiah yang rapi.
- **Modal Detail Produk:** Preview produk interaktif dengan pilihan warna dinamis yang otomatis mengubah foto produk, pilihan ukuran, kuantiti, serta tombol aksi hybrid:
  - **Pesan Langsung via WhatsApp** (checkout langsung 1 item tanpa lewat keranjang)
  - **+ Tambah ke Tas** (memasukkan pakaian ke keranjang belanja)
  - **Beli di Shopee** (membuka produk langsung di toko resmi Shopee)
- **Tas Belanja (Bag Drawer):** Manajemen keranjang lengkap dengan pengaturan jumlah, hapus item, dan tombol **Pesan Sekarang via WhatsApp** yang otomatis menyusun rincian pesanan terformat rapi ke nomor admin toko.
- **Belanja Per Setelan (Lookbook):** Inspirasi padu padan atasan dan bawahan menggunakan foto model beresolusi tinggi serta tombol beli setelan lengkap.
- **Dua Bab Koleksi (Chapters):** Navigasi sorotan koleksi sweater & rajutan dan atasan harian dengan scroll otomatis ke katalog.
- **Instagram CTA:** Terhubung langsung ke Instagram resmi brand.
- **100% Dinamis:** Seluruh pengaturan teks, harga, nomor WhatsApp admin, link Shopee, dan katalog produk tersimpan di file `content.json` sehingga siap diedit oleh pemilik toko melalui CMS bisnisnaikkelas.

## Teknologi yang Digunakan

- **Framework:** Next.js (App Router, Turbopack)
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS
- **Animasi & Interaktivitas:** Framer Motion
- **Icons:** Lucide React & Clean SVG

---

## Menjalankan Proyek Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/Alvynaja19/The-Joy.git
   cd The-Joy
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server development:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

4. **Build untuk produksi:**
   ```bash
   npm run build
   npm run start
   ```
